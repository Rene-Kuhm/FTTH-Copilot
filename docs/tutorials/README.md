# Tutorials

Documentación de **aprendizaje**: un camino paso a paso, con un objetivo concreto y un
resultado verificable al final. Cada tutorial arranca desde un estado conocido, no da por
sabido nada que no haya enseñado antes, y termina con algo que podés comprobar.

Los tutorials están ordenados por dificultad. No hace falta leerlos todos: el primero te
da el producto en 5 minutos, el último te muestra el motor de diagnóstico por dentro.

| Tutorial | Qué aprendés | Cuánto tarda |
|---|---|---|
| [1 — El demo en un comando](tutorial-1-el-demo-en-un-comando.md) | Levantar el producto completo con Docker y ver un dashboard con datos | 5 min |
| [2 — Tu primera consulta](tutorial-2-tu-primera-consulta.md) | Cómo el chat decide cuánto trabajar y qué es un veredicto de evidencia | 10 min |
| [3 — Entorno local](tutorial-3-entorno-local.md) | Levantar el stack de desarrollo, con Postgres, para tocar el código | 15 min |
| [4 — Una investigación de punta a punta](tutorial-4-una-investigacion.md) | Pedir un diagnóstico formal y leer sus hipótesis, su evidencia y sus versiones | 15 min |
